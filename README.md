# 一路向北 · Camino Portugués

直接以瀏覽器開啟 `index.html`。照片、CSS、JavaScript 和路線示意圖皆已嵌入，無需安裝或建置，離線也能閱讀。官方資料及攝影來源連結需要網路。

包含十個主題章節、雙路線切換、三組每日行程、每日距離估算、裝備勾選清單、手機版和減少動態效果支援。清單不會永久儲存。

## GitHub Pages

1. 將 `index.html` 放進儲存庫根目錄。
2. 在 Settings → Pages 選擇 Deploy from a branch，選取要發布的分支及根目錄，儲存。
3. 等待部署完成後，開啟 GitHub 提供的 Pages 網址。

此交付為可部署網站檔案，尚未發布到公開網址。

資料查核日期：2026-09-06。官方來源和圖片作者、授權均列於網頁。距離與天數為規劃範例；證書最新條款、渡河、住宿與天氣應在出發前再確認。地圖僅為順序示意，不可用於導航。
